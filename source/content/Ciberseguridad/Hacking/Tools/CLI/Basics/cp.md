
| Parámetro | Función                     | Ejemplo de sintaxis   |
| --------- | --------------------------- | --------------------- |
| `-r/-R`   | Copia recursiva             | `cp -r dir1/ dir2/`   |
| `-p`      | Conservar permisos y fechas | `cp -p file backup/`  |
| `-v`      | Verbose                     | `cp -v *.txt backup/` |
