Muestra memoria libre y usada, incluyendo swap y buffers.

```
free [opciones]
```

| **Parámetro** | **Función**                        | **Ejemplo**     |
| --------- | ------------------------------ | ----------- |
| `-b`      | Muestra en bytes.              | `free -b`   |
| `-m`      | Muestra en megabytes.          | `free -m`   |
| `-t`      | Muestra totales.               | `free -t`   |
| `-s`      | Poll continuo cada X segundos. | `free -s 2` |
| `-l`      | Detalles de memoria baja/alta. | `free -l`   |
