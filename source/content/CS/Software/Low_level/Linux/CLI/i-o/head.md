
| Parámetro | Función                       | Ejemplo de sintaxis    |
| --------- | ----------------------------- | ---------------------- |
| `-n N`    | Mostrar N primeras líneas     | `head -n 10 file.txt`  |
| `-c N`    | Mostrar N primeros bytes      | `head -c 512 file.bin` |
| `-q` `    | No mostrar nombres de archivo | `head -q *.log`        |
