
| **Comando/Parámetro**        | **Función**                                             | **Sintaxis de Ejemplo** |
| ------------------------ | --------------------------------------------------- | ------------------- |
| `alias`                  | Lista todos los alias definidos en la sesión actual | `alias`             |
| `alias nombre="comando"` | Crea un nuevo alias                                 | `alias ll="ls -la"` |
| `unalias`                | Elimina un alias específico                         | `unalias ll`        |
| `unalias -a`             | Elimina todos los alias de la sesión                | `unalias -a`        |
