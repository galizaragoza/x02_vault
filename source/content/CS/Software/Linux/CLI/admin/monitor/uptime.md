uptime shows current time, system uptime, logged-in users, and load averages (1/5/15 min)

| **Parameter**      | **Function**                                 | **Example**     |
| -------------- | ---------------------------------------- | ----------- |
| `-p, --pretty` | Human-readable uptime.                   | `uptime -p` |
| `-s, --since`  | Uptime start time (yyyy-mm-dd HH:MM:SS). | `uptime -s` |
