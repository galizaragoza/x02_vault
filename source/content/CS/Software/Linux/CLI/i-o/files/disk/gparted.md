```
gparted [dispositivo]
```

| **Parámetro (Flag)**              | **Función**                       | **Ejemplo de Sintaxis**                                                                 |
| ----------------------------- | ----------------------------- | ----------------------------------------------------------------------------------- |
| `-h`                          | Muestra ayuda.                | `gparted -h`                                                                        |
| `-v`                          | Muestra versión.              | `gparted -v`                                                                        |
| (Interfaz GUI: Crear)         | Crea partición vía menú.      | Lanzar `sudo gparted`, seleccionar disco, menú Partición > Nueva.                   |
| (Interfaz GUI: Eliminar)      | Elimina partición.            | Lanzar `sudo gparted`, seleccionar partición, menú Partición > Eliminar.            |
| (Interfaz GUI: Redimensionar) | Redimensiona/mueve partición. | Lanzar `sudo gparted`, seleccionar partición, menú Partición > Redimensionar/Mover. |
