#reference

**Go** (Golang) = lenguaje compilado, tipado estático, con recolección de basura y **concurrencia nativa**. Sintaxis simple, binarios estáticos sin dependencias → muy usado en tooling de seguridad (nuclei, subfinder, ffuf), backend y DevOps.

# Fundamentos

```go
package main

import "fmt"

func main() {
    fmt.Println("hola")
}
```

```bash
go run main.go        # compilar y ejecutar
go build              # binario estático
go mod init proyecto  # iniciar módulo
go get paquete        # dependencia
GOOS=windows GOARCH=amd64 go build   # cross-compile
```

# Tipos y declaración

```go
var x int = 5
y := "infiere tipo"          // := solo dentro de funciones
const Pi = 3.14
var s []int                  // slice (array dinámico)
m := map[string]int{"a": 1}  // mapa
type Punto struct{ X, Y int }
```

| Categoría | Tipos |
|-----------|-------|
| Numéricos | `int`, `int64`, `uint`, `float64`, `byte`, `rune` |
| Otros | `string`, `bool`, `error` |
| Compuestos | `array`, `slice`, `map`, `struct`, `pointer`, `channel` |

# Control de flujo

```go
if x > 0 { ... } else { ... }
for i := 0; i < 10; i++ { ... }   // único bucle (también while/forever)
for i, v := range slice { ... }
switch x { case 1: ...; default: ... }
```

# Funciones, errores e interfaces

```go
func divide(a, b int) (int, error) {
    if b == 0 { return 0, fmt.Errorf("división por cero") }
    return a / b, nil
}

r, err := divide(10, 0)
if err != nil { log.Fatal(err) }    // manejo idiomático de errores

defer f.Close()    // se ejecuta al salir de la función
```

```go
type Lector interface { Read() string }   // interfaces implícitas (duck typing)
```

# Concurrencia

El sello de Go: **goroutines** + **channels**. Ver [[GoRoutines]].

```go
go tarea()              // lanza una goroutine
ch := make(chan int)    // canal de comunicación
```
