**x8** es un buscador de parámetros escrito en Rust, diseñado para ser extremadamente rápido y capaz de manejar grandes volúmenes de datos.

| **Parámetro**       | **Función**                                     | **Ejemplo de Sintaxis**        |
| ------------------- | ----------------------------------------------- | ------------------------------ |
| `-u` / `--url`      | URL del objetivo.                               | `x8 -u "https://site.com/"`    |
| `-w` / `--wordlist` | Diccionario de parámetros a probar.             | `x8 -u URL -w params.txt`      |
| `-X` / `--method`   | Método HTTP (GET, POST).                        | `x8 -u URL -X POST`            |
| `-p` / `--proto`    | Protocolo a usar (http1, http2).                | `x8 -u URL -p http2`           |
| `--headers`         | Busca cabeceras HTTP en lugar de parámetros.    | `x8 -u URL --headers`          |
| `--v` / `--verbose` | Muestra información detallada del proceso.      | `x8 -u URL -v`                 |
| `--max-params`      | Número máximo de parámetros por petición.       | `x8 -u URL --max-params 100`   |
| `--body`            | Datos que se enviarán en el cuerpo del mensaje. | `x8 -u URL --body "auth=true"` |
| `-L`                | Sigue redirecciones                             |                                |
