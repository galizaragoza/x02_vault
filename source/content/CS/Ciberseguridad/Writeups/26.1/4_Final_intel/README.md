This is a project for my cyber intelligence class, where the objective was to develop a malware.

In my case, the exploit works in a hypothetical case in which initial access to a machine has already happened. The exploit is made of two files, one is meant to be executed on the target machine, and the other one is meant to be executed on the attacking machine (requirements are discussed later).

The target.py file requieres Python 3.9+, and for this reason the exploit is not practical for real case usage or CTFs, since it is meant to be used on Ubuntu 16.04 machines and said version
