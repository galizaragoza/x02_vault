#reference #Networking

**IP** (Internet Protocol) = protocolo de **capa de red** (OSI 3) que direcciona y enruta paquetes entre dispositivos a través de Internet. Sin conexión y *best-effort* (no garantiza entrega ni orden; eso lo aporta TCP arriba).

> Esta nota cubre la **teoría**. Para tablas de clases, CIDR, máscaras y cálculo de subnetting → cheatsheet [[IP_CS]].

## Routing

Cada router decide el siguiente salto según su **tabla de rutas**, comparando la IP destino con prefijos de red. El paquete viaja salto a salto hasta la red destino; el **TTL** se decrementa en cada router (evita bucles).

### IPv4 (32 bit)
4 octetos decimales (`192.168.1.1`). ~4.300 millones de direcciones → agotadas, de ahí NAT e IPv6.

### IPv6 (128 bit)
8 grupos hexadecimales (`2001:db8::1`, `::` colapsa ceros). Espacio inmenso, pensado para evitar NAT, autoconfiguración (SLAAC).

## Subnetting

Dividir una red en subredes usando bits de la parte de host. La **máscara**/CIDR marca cuántos bits son de red vs host. Cálculo y fórmulas → [[IP_CS]].

```
192.168.1.0/24  -> 256 direcciones, 254 hosts útiles
/26             -> bloques de 64
```

## NAT

**Network Address Translation**: traduce IPs privadas ↔ pública. Permite que muchos hosts internos compartan una IP pública (PAT) y oculta la red interna. Tipos: SNAT/masquerade (salida), DNAT/port-forwarding (entrada).

## Encapsulación

```
[ Datos app ] -> [ TCP/UDP segmento ] -> [ IP paquete ] -> [ Ethernet trama ]
```
