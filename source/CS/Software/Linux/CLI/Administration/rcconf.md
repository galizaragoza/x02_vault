| **Parámetro**        | **Función**                                   | **Ejemplo de sintaxis**             |
| ---------------- | ----------------------------------------- | ------------------------------- |
| `--help`         | Muestra ayuda del programa                | `rcconf --help`                 |
| `--version`      | Muestra versión del programa              | `rcconf --version`              |
| `--exclude=`     | Excluye servicios específicos de la lista | `rcconf --exclude=mysql,apache` |
| (sin parámetros) | Inicia interfaz interactiva               | `sudo rcconf`                   |
