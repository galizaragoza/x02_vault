**x8** es un buscador de parámetros escrito en Rust, diseñado para ser extremadamente rápido y capaz de manejar grandes volúmenes de datos.

# Basic
| **Parámetro**      | **Descripción**                                   | **Ejemplo de Sintaxis**    |
| ------------------ | ------------------------------------------------- | -------------------------- |
| `-u`, `--url`      | URL del objetivo (obligatorio).                   | `-u "https://target.com/"` |
| `-w`, `--wordlist` | Ruta al diccionario de parámetros.                | `-w params.txt`            |
| `-v`, `--verbose`  | Muestra el progreso y detalles de las peticiones. | `-v`                       |
| `--help`           | Muestra la ayuda de la herramienta.               | `--help`                   |
# Req
| **Parámetro**    | **Descripción**                                      | **Ejemplo de Sintaxis**   |
| ---------------- | ---------------------------------------------------- | ------------------------- |
| `-X`, `--method` | Método HTTP a utilizar (GET, POST, PUT, etc.).       | `-X POST`                 |
| `-p`, `--proto`  | Protocolo a usar: `http1`, `http2`.                  | `-p http2`                |
| `-H`             | Añade cabeceras personalizadas (Cookies, Auth).      | `-H "Cookie: user=admin"` |
| `-b`, `--body`   | Datos fijos para el cuerpo de la petición.           | `--body '{"id": 1}'`      |
| `--headers`      | En lugar de parámetros, intenta descubrir cabeceras. | `--headers`               |
| `--encode`       | Codifica los parámetros (ej. `url`).                 | `--encode url`            |
# Custom points
| **Código**     | **Función**                                                   | **Ejemplo de Uso**               |
| -------------- | ------------------------------------------------------------- | -------------------------------- |
| `{{%s}}`       | **Punto de inyección:** x8 reemplaza esto por los parámetros. | `-u "site.com/api?{{%s}}"`       |
| **En Query**   | Inyecta parámetros extra en la URL.                           | `-u "site.com/v1?user=1&{{%s}}"` |
| **En JSON**    | Inyecta dentro de un objeto JSON en el body.                  | `--body '{"data": { {{%s}} }}'`  |
| **En Headers** | Inyecta parámetros dentro de una cabecera.                    | `-H "X-Custom-Header: {{%s}}"`   |
# Rendimiento
| **Parámetro**              | **Descripción**                               | **Valor por Defecto / Ejemplo** |
| -------------------------- | --------------------------------------------- | ------------------------------- |
| `--max-params`             | Número de parámetros enviados por petición.   | `--max-params 100`              |
| `--concurrency`            | Número de hilos simultáneos.                  | `--concurrency 10`              |
| `--delay`                  | Tiempo de espera entre peticiones (ms).       | `--delay 500`                   |
| `-L`, `--follow-redirects` | Sigue las redirecciones (301, 302).           | `-L`                            |
| `--timeout`                | Tiempo de espera máximo para respuesta (seg). | `--timeout 10`                  |
# Detección y filtrado
|**Parámetro**|**Descripción**|**Ejemplo de Sintaxis**|
|---|---|---|
|`--status-code`|Filtra por código de estado HTTP.|`--status-code 200,403`|
|`--reflection-only`|Solo reporta si el valor se refleja en la respuesta.|`--reflection-only`|
|`--recheck`|Verifica de nuevo los parámetros encontrados.|`--recheck`|
|`--verify-method`|Prueba el parámetro con otros métodos si lo encuentra.|`--verify-method`|
|`--percent`|Establece el porcentaje de diferencia para detectar cambio.|`--percent 5`|
# Proxy / output
|**Parámetro**|**Descripción**|**Ejemplo de Sintaxis**|
|---|---|---|
|`-o`, `--output`|Guarda los resultados en un archivo.|`-o resultados.txt`|
|`-O`, `--output-format`|Formato del archivo: `plain`, `json`.|`-O json`|
|`--proxy`|Envía el tráfico a través de un proxy (ej. Burp Suite).|`--proxy "http://127.0.0.1:8080"`|
|`--replay-proxy`|Solo envía los parámetros **encontrados** al proxy.|`--replay-proxy "http://127.0.0.1:8080"`|
